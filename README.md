# Monkeytype Clone

A minimalist, highly customizable typing test platform inspired by [Monkeytype](https://monkeytype.com/). Built with React, Vite, and Tailwind CSS.

## Features

- **Minimalist Design**: Clean, distraction-free interface with a dark theme (`#323437`).
- **Real-time Typing**: Instant feedback on correct/incorrect characters with smooth cursor animations.
- **Customizable Timer**: Choose between 15s, 30s, or 60s test durations.
- **Results Analysis**: view your WPM (Words Per Minute), Accuracy, and Error count.
- **Responsive**: Works seamlessly on desktop.

## Tech Stack

- **Frontend**: [React](https://reactjs.org/) (v18)
- **Tooling**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Font**: [Roboto Mono](https://fonts.google.com/specimen/Roboto+Mono)

## Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1.  **Clone the repository** (or download usage):

    ```bash
    git clone https://github.com/yourusername/monkeytype-clone.git
    cd monkeytype-clone
    ```

2.  **Install dependencies**:

    ```bash
    npm install
    ```

3.  **Start the development server**:

    ```bash
    npm run dev
    ```

4.  **Open in Browser**:
    Visit `http://localhost:5173` to start typing!

## Usage

- **Start Typing**: The test begins automatically when you type the first character.
- **Restart**: Press `Tab` + `Enter` or click the restart button on the results screen.
- **Change Duration**: Click the time options (15 / 30 / 60) in the header.
